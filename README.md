# Ulyulyu game

A game of words with websockets

### Prerequisites

- Node.js (version from `.nvmrc`)
- Bun (version from `packageManager` field in `package.json`)

```sh
bun install --frozen-lockfile
```

### Development

```sh
bun run dev
```

### Checks

```sh
bun run format
bun run lint
bun run typecheck
bun run build
```
